# Mission 4 Reflection

My reflection here in the Laboratory Activity is that I learned every important concepts and differences between the two traditional Virtual Machines and containers. For me a virtual machine is usually run by a complete operating system to run it. and a Docker Container can be run from an image which is easy to process. That is why technologies like Docker provide a great solution to speed up the process of deploying applications.

The -p 8080:80 mapping is used because the Nginx web server in the container has to have a destination port to which incoming requests are forwarded to. Traffic to the container can be seen at localhost:8080 after the host port 8080 is allocated for the purpose.

Running docker rm will cease the operation of a Docker container. Consequently, all data inside the Docker volume will be deleted. Hence, it is extremely essential to take measures to guard data that is essential for the application to function correctly.

The primary advantage of this method is that it establishes a development and operations feedback loop. This is because the implementation of standards in the development and deployment processes increases consistency. This means developers are able to build applications that include specific dependencies, and operations staff is then able to run the same image in a production environment.
