# Mission Reflection

Through Laboratory Activity 9, I learned how automation can make cloud administration easier, faster, and more reliable. Managing hundreds of cloud servers manually would require a lot of time and effort. By using Bash scripts and Cron jobs, administrators can automate repetitive tasks such as backups and system maintenance. This reduces manual work and helps prevent human errors.

However, I also learned that automation can be dangerous when a script contains mistakes. For example, a destructive command scheduled to run on 1,000 servers could delete important files or interrupt services across many systems. This is why scripts should be reviewed, tested in a safe environment, and monitored before being deployed on a large scale. Backups and proper access controls are also important safeguards.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. Bash uses commands, variables, and instructions that execute step by step to perform tasks. Docker Compose uses YAML to describe application services, configurations, networks, and other resources. Both are useful for automation, but they solve different problems.

Looking back at Laboratories 1 to 9, my understanding of cloud computing has developed from learning basic cloud concepts to working with infrastructure, deployment, operations, security, and automation. I now understand that cloud computing involves more than running applications online. It also requires managing resources, protecting data, maintaining services, and using automation effectively.

The role I enjoyed most was the **Cloud Automation Engineer** because it allowed me to write a script that performs repetitive tasks automatically. Seeing the backup archive created after running my script helped me understand the practical value of automation. This activity also taught me that reliable automation requires careful planning, testing, documentation, and continuous improvement. Overall, this laboratory improved my confidence in using Linux commands and helped me appreciate the importance of automation in modern cloud environments.
