# Laboratory 05 – The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I deployed an S3-compatible object storage server using MinIO and Docker. I created a storage bucket named `client-photos` and uploaded a test file through the MinIO Web Console.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Access a cloud service through port forwarding.
- Create an object storage bucket.
- Upload an object to the bucket.
- Document cloud storage operations using Markdown.
- Update my GitHub Cloud Computing portfolio.

## Tools Used

- KillerCoda Playground
- Ubuntu
- Docker
- MinIO
- GitHub
- Web Browser
- Markdown

## Skills Learned

- Understanding different types of cloud storage.
- Deploying applications using Docker.
- Working with Docker environment variables.
- Using port forwarding.
- Creating and managing MinIO buckets.
- Uploading objects to cloud storage.
- Documenting technical work using Markdown.
