Laboratory 01 – Welcome to the Cloud

Mission Overview

This laboratory activity is the first mission in CCM101 –
Cloud Computing. It introduces the basic tools and practices
used by cloud engineers, including Linux, KillerCoda, GitHub,
and Markdown documentation.

Objectives

The objectives of this laboratory are:

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate Linux.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create a GitHub repository.
- Document technical work using Markdown.

Activities Performed

During this laboratory activity, I:

1. Accessed the KillerCoda Linux Playground.
2. Created and logged into a Linux user account.
3. Collected system information.
4. Created a workspace and Markdown files.
5. Created a GitHub repository.
6. Documented the laboratory activity.
7. Captured screenshots as evidence.

Linux Commands Used

The following Linux commands were used:

•	whoami
•	pwd
•	hostname
•	sudo useradd -m -s /bin/bash vrampo
•	sudo passwd vrampo
•	su – vrampo
•	cat /etc/os-release
•	uname -r
•	lscpu
•	free -h
•	df -h
•	cd ~
•	nano system-information.md
•	mkdir -p CloudComputing/Notes
•	find CloudComputing -maxdepth 2 -type d
•	nano CloudComputing/Notes/about-me.md
•	cat CloudComputing/Notes/about-me.md

Skills Learned

Through this laboratory, I learned how to:
- Access a cloud-based Linux environment.
- Navigate the Linux file system.
- Create users and manage permissions.
- Collect basic system information.
- Create directories and Markdown files.
- Use GitHub to maintain a technical portfolio.
- Document technical activities professionally.
